# «Семейный щит» 2.1.0: сервер, публикация, монетизация, события

Это не жёсткий сценарий, а список того, что должно получиться. В консолях действуй по смыслу.

## Что в архиве
- `build/family-shield-2.1.0.apk`: загружать в RuStore его (versionCode 3, подпись CN=Family Shield).
  `family-shield-2.1.0.aab` загружать, только если консоль требует AAB и не просит ключ подписи.
- `graphics/icon-512.png`: иконка.
- `graphics/screenshots/rustore-01…10.jpg`: скриншоты 1080×1920, грузить строго по порядку.
- `events/event-01…06.jpg`: обложки событий 2880×2160.
- `texts/RUSTORE_LISTING.md`: название, описания, ключевые слова, «Что нового», FAQ, обоснование разрешений.
- `texts/СОБЫТИЯ.md`: тексты, даты и цвета шести событий.
- `texts/PRIVACY.md`, `texts/TERMS.md`: политика и соглашение (на сайте они появятся после шага 1).

## 1. Сервер familyapp1.ru
Сервер: VPS FirstVDS 188.120.246.123, Ubuntu 24.04. Домен уже указывает на него. SSH снаружи режется,
поэтому работать только через веб-консоль FirstVDS. Команда установки:

    curl -fsSL https://clck.ru/3WcBfb | bash -s familyapp1.ru

Установщик сам ставит Docker, базу, сервер и HTTPS (Caddy) и включает автообновление с GitHub
каждые 10 минут. Готово, когда открываются:
- https://familyapp1.ru/health → `{"status":"ok",…}`
- https://familyapp1.ru/privacy и https://familyapp1.ru/terms

Если HTTPS не поднялся: `cd /opt/family-shield/shield/deploy && docker compose logs --tail 50 caddy`.
Если ошибка в самом начале и упоминается сеть: `curl -sI https://github.com | head -1`. Без интернета
на сервере установка не пройдёт, тогда нужно писать в поддержку FirstVDS.
После установки владелец должен сменить пароль root командой `passwd`: старый пароль светился в переписке.

## 2. Карточка в RuStore
- Приложение `ru.ubt.familyshield`: открыть существующее или создать новое.
- Тексты взять из `RUSTORE_LISTING.md`. Категория «Инструменты» или «Родителям», возраст 0+,
  «бесплатно с покупками».
- Ссылки: политика https://familyapp1.ru/privacy, соглашение https://familyapp1.ru/terms,
  сайт https://familyapp1.ru.
- Комментарий для модерации взять из раздела «Обоснование чувствительных разрешений».

## 3. Монетизация
Подключить платежи RuStore для приложения (договор и реквизиты в консоли, если ещё не сделано).
Создать товары, ID символ в символ:

| ID | Тип | Цена | Название |
|---|---|---|---|
| `shield_premium_month` | подписка, 1 месяц | 349 ₽ | Премиум на месяц |
| `shield_premium_year` | подписка, 12 месяцев, пробный период 7 дней | 2 490 ₽ | Премиум на год |
| `shield_family_max_month` | подписка, 1 месяц | 549 ₽ | Семья Макс на месяц |
| `shield_family_max_year` | подписка, 12 месяцев | 3 990 ₽ | Семья Макс на год |
| `shield_premium_lifetime` | постоянная покупка (неисчерпаемая) | 6 990 ₽ | Премиум навсегда |
| `shield_pack_elder` | постоянная покупка | 1 490 ₽ | Набор «Защита родителей» |
| `shield_pack_kids` | постоянная покупка | 1 490 ₽ | Набор «Детский контроль» |

Описания товаров: коротко, что даёт тариф («все функции защиты для всей семьи» и т. п.).

После этого в консоли RuStore создать ключ API с доступом к платежам и подпискам и проект
пуш-уведомлений. Вписать их на сервере в `/opt/family-shield/shield/deploy/.env`
(`RUSTORE_KEY_ID`, `RUSTORE_PRIVATE_KEY`, `RUSTORE_PUSH_PROJECT_ID`, `RUSTORE_PUSH_SERVICE_TOKEN`)
и выполнить `cd /opt/family-shield/shield/deploy && docker compose up -d`. Ключи вводит владелец
или расширение прямо в консоли сервера, в чат их не писать.

## 4. Модерация
Загрузить APK, проверить карточку и товары, показать владельцу. Отправлять на модерацию только
после его подтверждения.

## 5. События
Только после публикации первой версии. Подать все шесть событий из `СОБЫТИЯ.md`: это непрерывная
цепочка с 25.11.2026 по 18.06.2027, каждое по 59 дней (максимум RuStore — 60, одновременно можно
подать до 10 заявок). Если дата начала уже прошла, сдвинуть её на ближайший день. Событие
«7 дней Премиума бесплатно» подавать, только если у `shield_premium_year` включён пробный период.
