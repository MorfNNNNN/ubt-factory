# Семейный щит — Android-приложение для RuStore

Одно приложение для всей семьи:

- **Пожилые родители** — защита от телефонных мошенников: блокировка номеров
  из базы жалоб, предупреждение на экране звонка, тревога «банк открыт во время
  разговора с незнакомцем», защита кодов из СМС, предупреждение о программах
  удалённого доступа и APK не из магазина, анализ сообщений на мошенничество,
  SOS, определение падения, «Я в порядке», лекарства, простой режим с крупными
  кнопками.
- **Дети и подростки** — экранное время, расписания (сон, уроки), блокировка и
  одобрение приложений, локальный DNS-веб-фильтр с безопасным поиском,
  оповещения об опасных переписках (травля, груминг, вербовка «дропов» и на
  поджоги, суицидальные сигналы, наркотики, ставки), геолокация и геозоны,
  защита от удаления, SOS.
- **Взрослые** — семейная панель, оповещения, запросы детей, удалённая
  настройка, чат, проверка номера/ссылки/сообщения.

Принципы: **прозрачность** (на защищённом телефоне всегда видно уведомление и
что именно видит семья, есть экран согласия), **сквозное шифрование** (сервер
пересылает только зашифрованные конверты), **анализ на устройстве** (переписка
целиком никуда не передаётся — только предупреждение с короткой выдержкой).

## Структура

```
shield/
├── shared/   Kotlin/JVM: протокол, шифрование, движки распознавания, правила, DNS-кодек, тарифы
├── server/   Ktor-сервер: устройства, семьи, приглашения, почтовые ящики, покупки, базы угроз
├── app/      Android (Compose M3, Room, WorkManager, RuStore Pay/Push)
├── deploy/   docker-compose: PostgreSQL + сервер + Caddy (HTTPS)
└── docs/     политика, соглашение, тексты RuStore, монетизация, чек-лист запуска
```

### shared
- `crypto/` — AES-256-GCM конверты с AAD (семья | id сообщения | отправитель),
  подписи опекуна ECDSA P-256, коды сопряжения (QR / 26 символов Crockford),
  HKDF. Только JCA — один код на Android и сервере.
- `detect/` — нормализация русского текста (гомоглифы, невидимые символы,
  растянутые слова), стеммер Snowball, словари ~20 схем мошенничества и
  11 категорий детских рисков, анализ ссылок (подделка доменов банков и
  Госуслуг, IDN, APK), номеров (РФ, 8-800, зарубежные, скрытые), СМС-кодов,
  каталог приложений (171 банк из RuStore Pay SDK, удалённый доступ, VPN).
- `policy/` — движок экранного времени (лимиты, расписания через полночь,
  бонусы, пауза, одобрение), период охлаждения.
- `dns/` — разбор IPv4/IPv6/UDP/DNS, синтез ответов, хеш-множества доменов на
  миллион записей, безопасный поиск, блокировка обхода через DoH.
- `billing/` — тарифы, наборы, функции, подписанные токены прав.

### server
Ktor 3 + Exposed + PostgreSQL (H2 для разработки и тестов). Авторизация по
токену устройства (хранится только SHA-256), ограничение частоты запросов,
лимиты тарифа на число устройств, проверка покупок через RuStore Public API
(подписки V5, разовые покупки V2), пуши RuStore без содержимого («проснись и
синхронизируйся»), обезличенные жалобы на номера (публикация после 3 жалоб),
импорт списков доменов.

### app
- `core/` — настройки (DataStore, секреты запечатаны ключом Android Keystore),
  Room, API-клиент, синхронизация с исходящей очередью, обработка сообщений,
  биллинг, пуши, базы угроз, действия опекуна.
- `protect/` — фоновая служба, служба спецвозможностей, слушатель уведомлений,
  фильтр звонков, VPN-фильтр, администратор устройства, SOS, падение,
  напоминания, проверка безопасности, полноэкранные предупреждения.
- `ui/` — онбординг с согласием, мастер разрешений, панели опекуна/ребёнка/
  пожилого, пейвол, проверка мошенничества, чат, юридические экраны.

## Сборка

Требуется JDK 17+ и Android SDK (platform 36).

```bash
cd shield
./gradlew :shared:test :server:test          # 84 теста
./gradlew :app:testDebugUnitTest :app:lintDebug
./gradlew :app:assembleDebug                 # app/build/outputs/apk/debug
./gradlew :app:assembleRelease               # R8, подпись — см. ниже
SHIELD_SERVER_ONLY=true ./gradlew :server:fatJar
```

Параметры сборки (свойства Gradle `-P...`, переменные окружения или
`keystore.properties`):

| Свойство | Переменная | Назначение |
|---|---|---|
| `shield.serverUrl` | `SHIELD_SERVER_URL` | адрес сервера, напр. `https://api.ваш-домен.ru` |
| `shield.entitlementPublicKey` | `SHIELD_ENTITLEMENT_PUBLIC_KEY` | публичный ключ сервера для проверки тарифа |
| `shield.rustoreConsoleAppId` | `RUSTORE_CONSOLE_APP_ID` | ID приложения в консоли RuStore (Pay SDK) |
| `shield.rustorePushProjectId` | `RUSTORE_PUSH_PROJECT_ID` | проект push-уведомлений RuStore |
| `shield.supportEmail` | `SHIELD_SUPPORT_EMAIL` | e-mail оператора данных для экрана конфиденциальности |
| `shield.storeFile` и др. | `SHIELD_STORE_FILE`, `SHIELD_STORE_PASSWORD`, `SHIELD_KEY_ALIAS`, `SHIELD_KEY_PASSWORD` | ключ подписи релиза |

Без ключа подписи релиз подписывается отладочным ключом (только для проверки).
Без `entitlementPublicKey` все платные функции заблокированы (в debug-сборке
есть переключатель «Включить Премиум» для разработки).

## Сервер

```bash
cd shield/deploy
cp .env.example .env            # заполните домен, пароль БД, ключи RuStore
docker compose run --rm server keygen   # ENTITLEMENT_PRIVATE_KEY / PUBLIC_KEY
docker compose up -d
```

Размещайте сервер в российском дата-центре (152-ФЗ). Подробности —
`docs/LAUNCH_CHECKLIST.md`.
