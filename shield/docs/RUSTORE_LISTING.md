# Карточка приложения в RuStore

- **Название:** Семейный щит: защита от мошенников и родительский контроль
  (если ограничение длины — «Семейный щит»)
- **Пакет:** `ru.ubt.familyshield`
- **Категория:** Инструменты (альтернатива — «Родителям»)
- **Возрастной рейтинг:** 0+

## Краткое описание (до 80 символов)
Защита родителей от мошенников и безопасность детей — в одном приложении

## Полное описание

**Семейный щит — одно приложение, чтобы защитить всю семью.**

👵 **Пожилым родителям — защита от телефонных мошенников**
• Блокировка мошеннических номеров по базе жалоб пользователей
• Подсказка прямо на экране звонка: «Осторожно, похоже на мошенников»
• Тревога, если во время разговора с незнакомцем открыт банк
• Предупреждение, если код из СМС пришёл во время звонка
• Защита от программ удалённого доступа и «обновлений» не из магазина
• Проверка сообщений и ссылок на мошенничество
• Простой режим с крупными кнопками, SOS, «Я в порядке», напоминания о
  лекарствах, определение падения

👧 **Детям и подросткам — безопасность и разумные правила**
• Экранное время, режим сна и уроков, пауза одним нажатием
• Одобрение новых приложений и блокировка ненужных
• Безопасный интернет: фильтр сайтов 18+, азартных игр, мошенничества, безопасный поиск
• Предупреждения родителям, если ребёнку угрожают, травят, вербуют или
  пытаются обмануть — без чтения всей переписки
• Местоположение, геозоны «дом», «школа», кнопка SOS

🔐 **Приватность по умолчанию**
• Данные шифруются на телефонах семьи — даже мы их не видим
• Сообщения проверяются прямо на телефоне
• На защищённом телефоне всегда видно, что он под защитой и что видят близкие

🆓 **Бесплатно:** SOS, предупреждения о незнакомых звонках, проверка номеров,
ссылок и сообщений, режим сна, простой режим, проверка безопасности телефона,
семейный чат.
⭐ **Премиум:** вся защита от мошенников, полный родительский контроль, живая
карта и история, отчёты.

## Обоснование чувствительных разрешений (для модерации)

Приложение — семейная защита с согласием владельца устройства. Каждое
разрешение запрашивается в мастере настройки с объяснением, работа защиты
всегда видна (постоянное уведомление, экран «Что видят близкие»).

| Разрешение / API | Зачем |
|---|---|
| `BIND_ACCESSIBILITY_SERVICE` | Определяет открытое приложение: на телефоне ребёнка применяет лимиты и расписания, защищает настройки приложения от отключения; на телефоне пожилого предупреждает, если во время звонка с незнакомцем открыт банк, установщик приложений или программа удалённого доступа. Содержимое экрана не сохраняется и не передаётся. |
| `BIND_NOTIFICATION_LISTENER_SERVICE` | Локально проверяет входящие СМС и сообщения мессенджеров на признаки мошенничества (пожилые) и угроз ребёнку. Тексты не передаются; семье уходит только предупреждение с короткой выдержкой. |
| `BIND_SCREENING_SERVICE` (роль фильтра звонков) | Блокирует номера из базы жалоб и показывает предупреждение о незнакомых номерах. |
| `BIND_VPN_SERVICE` | Локальный DNS-фильтр: блокирует опасные сайты, включает безопасный поиск. Перехватываются только DNS-запросы, трафик не уходит на наши серверы. |
| `BIND_DEVICE_ADMIN` | Защита от удаления приложения ребёнком; при отключении родители получают уведомление. Политики устройства не используются. |
| `PACKAGE_USAGE_STATS` | Подсчёт экранного времени по приложениям. |
| `QUERY_ALL_PACKAGES` | Список приложений для родительского контроля и поиск опасных программ (удалённый доступ, банковские трояны). |
| `SYSTEM_ALERT_WINDOW` | Предупреждение поверх экрана входящего звонка. |
| `ACCESS_FINE/BACKGROUND_LOCATION` | Местоположение для семьи, геозоны, SOS. |
| `READ_CONTACTS`, `READ_PHONE_STATE` | Отличить знакомый номер от незнакомого; знать, идёт ли разговор. |
| `CALL_PHONE`, `SEND_SMS` | Только кнопка SOS: звонок и СМС с координатами доверенным контактам. |
| `FOREGROUND_SERVICE_SPECIAL_USE` | Постоянная видимая служба защиты. |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | Чтобы защита не отключалась системой. |
| `SCHEDULE_EXACT_ALARM` | Точные напоминания о лекарствах. |
| `CAMERA` | Сканирование QR-кода при подключении телефона к семье. |

Скрытие иконки, скрытый режим, запись звонков и экрана, доступ к паролям — **не
реализованы и не будут**.
